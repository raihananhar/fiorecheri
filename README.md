Aplikasi kasir offline untuk coffee shop Fiore Chéri yang dibuat untuk mempermudah transaksi dan manajemen penjualan tanpa perlu koneksi internet. Aplikasi ini dirancang agar ringan, cepat, dan mudah digunakan oleh kasir dalam operasional sehari-hari.

Fitur utama:
Input pesanan dengan cepat dan mudah
Hitung total harga otomatis
Support berbagai metode pembayaran (Cash, QRIS, Debit)
Cetak struk langsung ke printer
Dashboard laporan transaksi harian
